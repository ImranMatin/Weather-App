# Weather-App

A simple web application built using **HTML, CSS, and JavaScript** that displays weather information. The app displays **Current Temperature, Conditions, Humidity, and Wind Speed**, as well as a **5-day Weather Forecast** for any city.

## Features
- View current temperature and weather conditions
- Display humidity and wind speed
- 5-day weather forecast
- Responsive design for both desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API (if used)

## Installation / Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/weather-app.git

2. Navigate to the project folder:
   cd weather-app

3. Open index.html in your web browser to run the app.

Note: If the app uses an API key (e.g., OpenWeatherMap), make sure to insert your API key in the appropriate JavaScript file.

## Usage

- Open the app in your browser.

- Enter a city name in the search box.

- Click "Search" to view the current weather and 5-day forecast.
