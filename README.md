# Weather-App

A simple web application built using **HTML, CSS, and JavaScript** that displays weather information. The app displays **Current Temperature, Conditions, Humidity, and Wind Speed**, as well as a **5-day Weather Forecast** for any city.

## Features
- View current temperature and weather conditions
- Display humidity and wind speed
- 5-day weather forecast
- Responsive design for both desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API (if used)
